BRUCE CONNECTIONS

Files:
  index.html       The game itself.
  puzzle-data.js  The puzzle. Edit this for a new game.

Hosting:
  Upload both files to the same folder on any static web host.

Puzzle format:
  There must be exactly 4 groups and exactly 4 unique words/phrases per group.

Test locally:
  Double-click index.html. Because puzzle-data.js is loaded as a normal script,
  the game works locally without a web server.
